Entry for the [make.fun](https://make.fun/c/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3) competition **"Everyday Wonder, Two Days to Find the Line"**.

`main.py` writes one sentence (137 characters, within the 1–200 limit) to `/output/entry.txt` — a lift that arrives empty yet still humming the last stranger's song, so the rider spends one floor inside somebody else's evening.

> The lift doors open on an empty car still humming the last stranger's song, and for one floor I am riding inside somebody else's evening.

The twist is the lift as an accidental jukebox of strangers: the wonder is not the ride, it is borrowing a stranger's evening for exactly one floor.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
